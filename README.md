# Absolute-Dollar-Agent---Ultron-Alpha

Absolute Dollar Agent (ULTRON Alpha) is a Glass Box Augmented Intelligence Agent written as a Pine Script indicator. 

This is a Multi-Timeframe Market-Analysis Engine built around a single idea: that Price can be Read as a System of observable states, and that those States can be organized into a Spatial and Contextual Framework that helps you see Structure, Direction, Momentum, Volatility, and Session Context without one layer hiding another. 

This is not artificial intelligence. It is not machine learning. It is not a trained model. It is a deterministic, transparent, rule-based system that applies established market concepts (ICT, SMC, Hull, RSI, ATR, Fibonacci) through a weighted fusion architecture — and shows you every step of the reasoning.

ULTRON Alpha is a decision-support agent — an Augmented Intelligence layer between You and the Market.
